# 恒视科技 EverWatch — Below the Fold

一个滚动驱动的恐怖互动网站。起初是一个精致、可信的智能家居监控品牌营销站；
随着你向下滚动，文案、配色、画面与声音逐渐腐化，最终坠入一段完整的恐怖电影式终局。

> ⚠️ **内容警告**：含闪烁画面、突发画面（jump scare）与合成音效。
> 光敏性癫痫患者请谨慎浏览。站点已内置提示条，并支持 `prefers-reduced-motion`
> （自动关闭闪烁、跳吓与大部分动画）。

## 打开方式

纯静态、零依赖、零网络请求 —— **直接用浏览器打开 `index.html` 即可**（`file://` 完全可用）。

也可以起一个本地服务器：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

**建议戴耳机。** 所有音效（低频嗡鸣、风声、心跳、耳语、呼吸、跳吓刺声）均由
WebAudio 实时合成，没有任何音频文件。受浏览器自动播放策略限制，声音会在你
第一次点击/按键后启动；右上角可随时开关。

## 体验流程（六个阶段）

| 滚动进度 | 阶段 | 发生什么 |
| --- | --- | --- |
| 0–12% | 0 · 正常 | 一个可以拿去融资的营销站：英雄区、数据、功能、评价、价格、FAQ |
| 12–30% | 1 · 微妙 | Logo 的眼睛开始跟着你的鼠标；某条评价有点不对劲；“0 起隐私泄露事故”变成“0 起**被发现的**事故” |
| 30–50% | 2 · 异样 | 灯光熄灭（主题切换）；文案开始自己重写；插画窗户里出现一张脸；App 演示画面切到走廊；低频嗡鸣响起；Cookie 提示“我们已经记住你了” |
| 50–70% | 3 · 崩坏 | 纯黑血红；卡片倾斜；评价者的眼睛变成黑洞；底部跑马灯“不要往下滚动”；心跳声随滚动加速；停下不动会收到低语 |
| 70–88% | 4 · 故障 | 屏幕裂纹、扫描线、RGB 撕裂、页面抽搐；假监控 HUD“● REC CAM-07 · 你的房间”；一次性 jump scare；标题栏变成“它在你身后” |
| 88–100% | 5 · 终局 | 走廊。吊灯每闪一次，尽头的人形就近一步。灯灭。黑屏。然后那张脸贴近屏幕，瞳孔跟着你的鼠标，逐字打出四行话。左下角：“信号源：你身后” |

其它细节：

- 浏览器标签标题与 favicon 随阶段腐化（最后变成一只红眼）。
- 页脚实时显示“你已停留 mm:ss —— 足够它记住你的脸”。
- 到达过终局后，**往回滚也回不到正常**：站点被永久“污染”（恐惧值下限 34%）。
- 终局右下角有「逃离」按钮：一声刺响后重置整站，回到顶部，附赠一句“你逃出来了。这次。”
- 连点三次 Logo 有彩蛋。

## 预览 / 调试参数

- `index.html?stage=0..5` — 锁定在指定阶段（截图、调试用）
- `index.html?stage=5&phase=face` — 直达终局脸部特写
- `index.html?mute=1` — 静音

## 验证

```bash
node tools/verify.mjs
```

使用本机 Chrome 无头模式 + CDP（无 npm 依赖），真实滚动遍历全部阶段，
断言阶段切换、终局序列、上滑中止、污染残留、逃离重置，并截图到 `previews/`。
当前结果：**12/12 通过，无 JS 运行时错误**。

## 文件

```
index.html      页面结构、全部 SVG 素材、各阶段腐化文案（data-s1..s4）
styles.css      主题阶段、连续恐惧变量 --dread、故障/闪烁/终局样式
script.js       滚动引擎、文字乱码、眼球追踪、WebAudio 合成、终局时序
tools/verify.mjs 无头浏览器端到端验证
previews/       各阶段验证截图
```

## 技术要点

- **连续 + 离散双轨**：`--dread`（0..1）连续驱动暗角、噪点、滤镜、画面交叉淡化；
  `data-stage`（0..5）离散驱动文案重写与主题“熄灯”，保证任何停留位置都有足够对比度。
- **文字腐化**：每个可腐化元素携带 `data-s1..s4`  alternate 文案，阶段变化时以
  乱码扫描（glitch scramble）过渡；回滚时恢复原始 HTML。
- **零素材**：插画、头像、走廊、那张脸全部为内联 SVG；音效全部实时合成。
- **可访问性**：`prefers-reduced-motion` 降级；提示条可关闭；音效可开关。
