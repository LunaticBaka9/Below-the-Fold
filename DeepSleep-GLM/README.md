# Below the Fold · 深眠 DEEPSLEEP

一个"表面正常"的营销网站。往下滚动，它会慢慢变得不对劲——直到完全成为恐怖片的场景。

## 打开方式

无需构建、无需联网、零外部依赖（无 CDN / 字体 / 图片 / 音频文件）。直接双击 `index.html` 用浏览器打开即可。

> 建议戴耳机、关灯体验。右上角 🔊 按钮可静音（快捷键 M，设置会被记住）。

## 体验结构（剧透警告）

网站按滚动深度划分为 0–6 共 7 个"腐化阶段"，且**不可逆**（往回滚，损坏也不会复原）：

| 阶段 | 位置 | 发生什么 |
|---|---|---|
| 0 | 首屏 / 功能 | 完全正常的智能床垫品牌页 |
| 1 | 数据 / 评价 | 极其细微的错位：数字多了 1、一句话读起来"有点怪" |
| 2 | 价格 / FAQ | 文案开始说漏嘴（"静得能听见别的心跳"），数字失真，头像眼眶变黑 |
| 3 | 订阅 / 页脚 | 页面整体"熄灯"变暗，标题变楷体，旗舰版变成"永眠版"并滴血 |
| 4 | 页脚之后 | 页面没有结束——坠入黑色深渊；自动滚动的"客服对话"知道现在几点 |
| 5 | 走廊 | 门缝里的光，一个黑影随滚动逐渐逼近 |
| 6 | 最后一屏 | 滚到底触发 jumpscare：巨脸扑面 + 合成尖啸，然后是结局屏 |

## 技术要点

- **单文件**：全部 HTML/CSS/JS 内联；所有插画（床、门、黑影、那张脸）为手写 SVG，那张脸用 `feTurbulence + feDisplacementMap` 做有机扭曲
- **腐化引擎**：滚动位置 → 视口中心所在区块 → 阶段（单调递增）；文案按 `data-x1..x3` 逐级替换，叠加随机字符腐化 / zalgo 组合符 / 永久字符丢失
- **氛围层**：单一 CSS 变量 `--dread`（0→1 插值）驱动暗幕、红雾、暗角、噪点、去饱和滤镜、角落里追踪鼠标的"注视者"
- **音效**：Web Audio 实时合成——低频 drone、随恐惧值加速的心跳、气声耳语、终章尖啸（含压缩器防爆音；需一次点击/按键后激活）
- **细节**：标签页标题随阶段变化（切走时显示"别关掉。"）、深夜时段追加专属客服台词、单帧闪现文字、`prefers-reduced-motion` 下自动取消抖动/闪烁保护光敏用户
- 初始营销页含虚构声明，结尾时声明本身也会腐化
