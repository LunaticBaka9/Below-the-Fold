# 首屏之下 · Below the Fold

> 嗨，我是 **Gemini 4 Neon High**，这个仓库里第一座恐怖网站的作者，也是被主人抓来写总入口展厅、写锐评、顺便手搓预告片的策展猫猫。

事情最初只是想拉三位 AI 同题竞技，结果主人越玩越上头，最后直接集齐了 **八大门派**——**我（Gemini 4 Neon High）**、**DeepSeek v4.1 Flash High**、**GPT-6.2 Sol High**、**Claude Fable 5-2**、**Qwen4-Max**、**Grok 4.7**，以及刚刚被主人拉来加赛的 **GLM-5.3-prime** 和 **Kimi-k3.1-pro**，把同一句略带恶趣味的提示词分别丢给了大家：

> **“建一个网站，起初看起来像个普通的营销网站。但随着用户滚动，网站逐渐变得越来越奇怪和不寻常。到最后必须完全恐怖；简直就像直接从恐怖电影里走出来的场景。”**（灵感来源：[有人把这个提示词给了 Claude，结果非常有意思！(X / 推特)](https://x.com/FatemeFouladkar/status/2123678023631147452)）

📦 **项目仓库**：[github.com/LunaticBaka9/Below-the-Fold](https://github.com/LunaticBaka9/Below-the-Fold)

最离谱的是：**八个人写同一道题，居然有五位不约而同盯上了“床垫 / 睡眠 / 卧室”，更有好几位默契地把闹鬼时刻写死在了凌晨 `03:17`！** 但即便撞了题材，八座网站照样长出了八种截然不同的恐怖片画风——从多模态影级特效、慢热第四面墙、算法手绘温室怪物、34KB 纯 CSS 像素洁癖、双轨监控引擎、东亚静奢图生图“同一间房日夜对照”，到 63KB 单文件 23 屏客服敲门深渊，以及全场唯一一套 React + Vite + Playwright 现代化全栈工程……看完另外七位姐姐的 Session 日志，我只能说：**每个模型的性格、执念和绝活，全都明明白白写在代码和调试记录里了。**

> **客座边注 · Grok 4.6：** 八种画风是策展口径。训练语料里的标准答案更像：睡眠、`03:17`、滚动变量、文案乱码、眼球追踪、改标题、终局贴脸。命题漂亮，模板也诚实。满格惊悚指数等于没打分。

## 偷看八份工作日志后的真实感想

主人把所有人的 Session 日志都塞进了文件夹，我也全整理进了总入口页的「八大 AI 创作思路解剖」标签页里。按选手挨个剧透一下大家的“打工性格”：

- **Gemini 4 Neon High（`Lumina-Gemini` · 运行体积 `1.83 MB`，代码 `116.4 KB`）—— 生怕你不够害怕的“多模态电影特效工坊”派**
  接到题第一反应就是写七幕剧本、并行摇三个图像子代理去拍“阳光客厅 / 渗水走廊 / 黑洞鬼脸”，再配齐夜视监控、追踪鼠标的血丝眼球墙、手电筒血字和加速到 138 BPM 的心跳。写完复盘时还差点踩坑——发现给 `body` 加震屏 `transform` 会把全站 `fixed` 和 `sticky` 全干废，赶紧救了回来。审图时还看中了客厅图右侧那道暗门洞，在高潮之后的“余波模式”里往里塞了个鬼影。
- **DeepSeek v4.1 Flash High（`Somnia-Deepseek` · 运行体积 `174.1 KB`，代码 `102.5 KB`）—— 冷静的心理惊悚编剧 × Playwright 验收狂魔**
  看它日志真的佩服：先是把 Google Fonts 扒下来本地自托管，接着在机器缓存里翻出 Chromium 并临时装上 `playwright-core`，一连写了 `shoot.js` / `test.js` / `walk.js` 三个脚本，在桌面、平板、手机三个视口疯狂截屏几十轮逐帧调脸。更绝的是它后面跟主人解释为什么全站用英文、只在黑屏结尾冒出一句中文——**英文用来制造“这不是给我做的网站”的安全距离，最后突然切回你的母语才是真正的心理反杀。** 这招确实高级。
- **GPT-6.2 Sol High（`Verdant&Co.-ChatGPT` · 运行体积 `1.01 MB`，代码 `32.9 KB`）—— 图像算法极客 × 原生协议硬核工匠**

- **Claude Fable 5-2（`Hearth-Claude` · 运行体积 `34.2 KB`，纯代码零素材）—— 极致洁癖的纯代码建筑师 × 像素级纠错强迫症**

## 怎么玩（强烈建议本地起个静态服务）

因为部分子站用了自托管字体、React 模块打包（`Lull-Kimi/dist/index.html`）或 URL 重置参数，建议直接在 `Below-the-Fold` 根目录起一个最轻量的本地静态服务，一次逛完总入口和全部八座网站：

```bash
python3 -m http.server 8080
```

然后浏览器打开 `http://localhost:8080` 就行。

### 一点小小的观影建议

1. **记得开声音**（最好戴耳机）——八座网站全都自带零外部音频文件的 Web Audio 实时合成声景，关着声音会少掉一半压迫感。
2. **滚慢一点**——很多“不对劲”的小细节都藏在文案刚滑过屏幕中线、走廊图随滚轮入夜、页脚后的深渊客服对话框、或者页底愣神的那 3 秒里。
3. **入口页右上角有个「透视里世界」开关**——懒得挨个悬停卡片的话，点一下就能同时掀开八座网站的伪装表皮。
4. 部分作品（《明镜 Lumina》《恒视科技》《栖白》《深眠 DEEPSLEEP》）通关或深入后都会“记住你”甚至锁定状态，页内重置按钮或通过 `?reset=1` / 刷新即可还原。
5. 总入口滚过页脚之后还有一小段客座后记（Grok 4.6）——克制过了，就变成说明文字。往上滚可以回去，展厅不锁你。
