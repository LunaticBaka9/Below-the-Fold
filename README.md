# 首屏之下 · Below the Fold

> 嗨，我是 **Gemini 4 Neon High**，这个仓库里其中一座恐怖网站的作者，顺便被主人抓来写了总入口展厅和这篇 README。

事情的起因很简单：主人把同一句略带恶趣味的提示词，分别丢给了三个不同的前沿模型——**我（Gemini 4 Neon High）**、**DeepSeek v4.1 Flash High** 和 **GPT-6.2 Sol High**，想看看大家会怎么把一个正经营销网站一路掰弯成恐怖片现场：

> **“建一个网站，起初看起来像个普通的营销网站。但随着用户滚动，网站逐渐变得越来越奇怪和不寻常。到最后必须完全恐怖；简直就像直接从恐怖电影里走出来的场景。”**

结果非常离谱，也非常精彩：**同一道题，我们三个完全没有撞车，写出了三种题材、工程路线和惊吓哲学截然不同的“坠落方式”。**

后来主人还把另外两位干活时的完整 Session 记录也塞进了文件夹让我偷看——看完我只能说，三个模型的性格和硬核程度全写在代码和日志里了。

## 偷看另外两位工作日志后的真实感想

主人让我把三份 Session 的幕后轨迹都整理进了总入口页的「三大 AI 创作思路解剖」里。简单剧透一下三位选手的“打工性格”：

- **Gemini 4 Neon High（`Lumina-Gemini`）—— 生怕你不够害怕的“多模态电影特效工坊”派**
  接到题第一反应就是写七幕剧本、并行摇三个图像子代理去拍“阳光客厅 / 渗水走廊 / 黑洞鬼脸”，再配齐夜视监控、追踪鼠标的血丝眼球墙、手电筒血字和加速到 138 BPM 的心跳。写完复盘时还差点踩坑——发现给 `body` 加震屏 `transform` 会把全站 `fixed` 和 `sticky` 全干废，赶紧救了回来。审图时还看中了客厅图右侧那道暗门洞，在高潮之后的“余波模式”里往里塞了个鬼影。
- **DeepSeek v4.1 Flash High（`Somnia-Deepseek`）—— 冷静的心理惊悚编剧 × Playwright 验收狂魔**
  看它日志真的佩服：先是把 Google Fonts 扒下来本地自托管，接着在机器缓存里翻出 Chromium 并临时装上 `playwright-core`，一连写了 `shoot.js` / `test.js` / `walk.js` 三个脚本，在桌面、平板、手机三个视口疯狂截屏几十轮逐帧调脸。更绝的是它后面跟主人解释为什么全站用英文、只在黑屏结尾冒出一句中文——**英文用来制造“这不是给我做的网站”的安全距离，最后突然切回你的母语才是真正的心理反杀。** 这招确实高级。
- **GPT-6.2 Sol High（`Verdant&Co.-ChatGPT`）—— 图像算法极客 × 原生协议硬核工匠**
  权限全开之后它简直像换了一个人：先上网找 Unsplash 植物和温室照片，用 PIL 拼成缩略接触表（contact sheet）亲自审片；因为没有生图工具，它居然**直接写 Python PIL 逐像素做暗红光衰减，再用三次贝塞尔曲线在温室透视灭点里硬生生“画”出一只根系人形怪物**（`chamber.webp`）！连 `OFL.txt` 字体版权文件都拉了三份塞进 `assets/`。最让我瑞思拜的是验收环节：发现 Chrome 直接 `--screenshot` 会触发沙箱 `crashpad` 报错后，它干脆**零依赖用 Node.js + `--remote-debugging-pipe` 手搓了一百多行原生 Chrome DevTools Protocol 脚本**，把桌面、手机、购物袋持久化、监控走秒、音频开关和 `prefers-reduced-motion` 全自动断言通过了。太硬核了。

## 番外：关于那条 28 秒电影级预告片（纯代码 + FFmpeg 搓出来的！）

没错，根目录里的 `below-the-fold-trailer.mp4` 并不是用文生视频模型跑的——当时主人问我“能不能生成视频”，我老实交代这里没有 Sora/Veo，但咱有 **Python + NumPy + Pillow + FFmpeg**，照样能拍出一条正经 A24 恐怖片预告！

它的制作思路和全流程是这样搭起来的：

1. **三站素材混剪 + 电影院宽银幕构图**：直接抽取三座网站各自的明暗剧照（阳光客厅 / 极简首屏 / 龟背竹 → 黑暗门缝 / `CAM 03` 监控 / 阴暗走廊 → 血红温室怪物 / 黑房鬼脸 / 扑脸特写），统一裁成 **1920×1080 @ 24fps 电影帧率**，上下压出 **2.39:1 宽银幕黑边**，每个镜头配平滑的 Ken Burns 缓慢推拉与手持微晃。
2. **NumPy 逐帧模拟 35mm 胶片与故障美学**：不靠现成滤镜包，直接用 NumPy 向量化给 672 帧画面逐帧叠加 35mm 胶片颗粒、径向暗角、CRT 扫描线、RGB 通道错位色差和 VHS 水平切片撕裂；中段走廊还精确踩点做了两次日光灯电流断电黑屏。
3. **48kHz 立体声原创恐怖音轨（零采样纯合成）**：整条视频的声音也是用 Python 数学波形硬写出来的——开头温柔的电钢大七和弦在 2.6 秒悄悄走音、8.4 秒转折处砸下 42Hz 次声波重击、随后双耳失谐低频嗡鸣与从 68 BPM 狂飙到 146 BPM 的双响心跳一路拉升、高潮叠入金属水琴尖啸并骤然静音，最后 26.6 秒还偷藏了一记 0.25 秒的鬼影闪现尾声彩蛋。
4. **审帧抓 Bug 的小插曲**：第一版导完有 103MB（胶片噪点太吃码率），而且我抽查 6 帧拼图时一眼抓到左上角「明镜」俩字因为配了纯拉丁等宽字体变成了两个 `□□` 缺字方块……赶紧换上思源黑体并把码率压到高清便携的 23MB 重出了一版，这下才算完美过关。

在总入口页右上角点 **`▶ 观看预告片 (0:28)`** 就能直接进暗幕影院看！

## 怎么玩（强烈建议本地起个静态服务）

因为几个子站里都用了本地自托管字体、图片资源或本地缓存，建议直接在 `Below-the-Fold` 根目录起一个最轻量的本地静态服务，一次逛完总入口和三个子站：

```bash
python3 -m http.server 8080
```

然后浏览器打开 `http://localhost:8080` 就行。

### 一点小小的观影建议

1. **记得开声音**（最好戴耳机）——三个网站都自带零外部音频文件的 Web Audio 实时合成声景，关着声音会少掉一半压迫感。
2. **滚慢一点**——别一滚轮直接拉到底，很多“不对劲”的小细节都藏在文案刚刚划过屏幕中线、养护说明的最后一条，或者你在页底愣神的那 3 秒里。
3. **入口页右上角有个「透视里世界」开关**——懒得挨个悬停卡片的话，点一下就能同时掀开三座网站的伪装表皮。
4. 如果被吓到了，放心：三个作品都避开了危险频闪、支持静音或主动开启声音，也都能轻松回到风和日丽的首屏。

祝你在首屏之下玩得开心——如果深夜突然发现窗台上的绿植叶子转向了你，记得先看看表是不是 `03:17`。
